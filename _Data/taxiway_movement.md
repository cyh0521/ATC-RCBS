## 一、離場動線

### 所有機位通用流程

1. **後推**：機頭朝北（朝航廈），向南後推退至 TWY N 中心線（y=388）
2. **轉向**：後推完成，機頭轉向東或西（依指派跑道決定）
3. **滑行**：沿 TWY N 滑行至對應等待點
4. **等待**：在等待點等候塔台起飛許可
5. **進入跑道**：經連接道進入跑道，對齊跑道中心線
6. **起飛**

### RWY06 起飛（向東）

- 等待點：**H-D** (464, 388)
- 進跑道連接道：**TWY D**
- 所有機位後推後，沿 TWY N 向西滑行至 H-D

| 機位群 | 後推方向 | TWY N 滑行方向 | 距離 |
|--------|----------|---------------|------|
| N1–N6 | 向南 | 向西（長） | 遠 |
| N7–N9 | 向南 | 向西（中） | 中 |
| M1–M3 | 向南 | 向西（短） | 近 |

### RWY24 起飛（向西）

- 等待點：**H-A** (2491, 388)
- 進跑道連接道：**TWY A**
- 所有機位後推後，沿 TWY N 向東滑行至 H-A

| 機位群 | 後推方向 | TWY N 滑行方向 | 距離 |
|--------|----------|---------------|------|
| N1–N3 | 向南 | 向東（短） | 近 |
| N4–N6 | 向南 | 向東（中） | 中 |
| N7–M3 | 向南 | 向東（長） | 遠 |

## 二、進場動線

### RWY06 降落（從西飛入，向東觸地）

- 觸地區：跑道西段（DTHR 附近，x≈60）
- 飛機向東減速後，從東側連接道脫離

**脫離連接道選擇：**

| 目標機位 | 建議脫離道 | 理由 |
|----------|-----------|------|
| N1–N3 | **TWY A** (2491) | 距離最近，直接北上 |
| N4–N6 | **TWY B** (1967) | 適中距離 |
| N7–N9 | **TWY B** (1967) | 減速後可達 |
| M1–M3 | **TWY B** (1967) | 脫離後向西滑行 |

脫離後路線：連接道北上 → TWY N → 向左/右滑行至機位

### RWY24 降落（從東飛入，向西觸地）

- 觸地區：跑道東段（THR24 附近，x≈2490）
- 飛機向西減速後，從西側連接道脫離

**脫離連接道選擇：**

| 目標機位 | 建議脫離道 | 理由 |
|----------|-----------|------|
| N1–N6 | **TWY B** (1967) | 減速後可達，向東回TWY N |
| N7–N9 | **TWY C** (1053) | 慢速機適用，距離合適 |
| M1–M3 | **TWY C** (1053) 或 **TWY D** (464) | 西側機位，C/D道最近 |

脫離後路線：連接道北上 → TWY N → 向左/右滑行至機位

---

## 三、後推規則

- **所有機位**：機頭朝北（朝向航廈方向）停靠
- **後推方向**：向南，退至 TWY N 中心線（y=388）
- **後推完成**：轉向後開始沿 TWY N 正常滑行
- Fire Station（x≈1946）不影響 TWY N 飛機行進
